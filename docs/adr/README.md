## Format och livscykel

En ADR beskriver kontexten vid beslutstillfället, beslutet, positiva och negativa konsekvenser samt övervägda alternativ. Ett accepterat beslut ändras inte i efterhand annat än rättning av språk eller länkar. En ny ADR ersätter beslutet och länkar till den gamla.
